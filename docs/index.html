mesh2gpx

Convert Meshtastic position log CSV exports to GPX track files

Python ≥ 3.9 uv tool install No dependencies GPX 1.1

Overview

mesh2gpx is a zero-dependency command-line tool that converts Meshtastic position log CSV exports into standard GPX 1.1 track files. The resulting GPX files can be imported into any mapping application that supports the format — including Reitti, Garmin BaseCamp, Google Earth, and more.

Installation

Install with uv (recommended):

uv tool install git+https://github.com/brandonleon/mesh2gpx

Or clone and install locally:

git clone https://github.com/brandonleon/mesh2gpx
cd mesh2gpx
uv tool install .

Usage

mesh2gpx <csv_file> [-o <output.gpx>]

The output file defaults to the same name as the input with a .gpx extension:

# Produces track_log.gpx in the same directory
mesh2gpx track_log.csv

# Specify a custom output path
mesh2gpx track_log.csv -o my_route.gpx

Arguments

ArgumentDescriptionRequired
csv Path to the Meshtastic CSV position log export Yes
-o / --output Output GPX file path. Defaults to input filename with .gpx extension No

CSV Format

mesh2gpx automatically detects column names in a case-insensitive, whitespace-tolerant way. The following field aliases are supported:

DataAccepted column names
Latitudelatitude, lat
Longitudelongitude, lon, long
Timestamptimestamp, time, date
Elevationaltitude, alt, elevation
Timestamps are expected in MM/DD/YY HH:MM format and are converted to ISO 8601 for GPX compliance. Rows with unrecognized timestamp formats are still included — the raw value is used as-is. Rows missing latitude or longitude are skipped.

Example CSV

timestamp,latitude,longitude,altitude
04/20/26 09:14,37.7749,-122.4194,52
04/20/26 09:15,37.7751,-122.4189,53
04/20/26 09:16,37.7754,-122.4183,54

Output

mesh2gpx writes a GPX 1.1 file containing a single track with one segment. Each row from the CSV becomes a <trkpt> element with optional <time> and <ele> children. 

<?xml version='1.0' encoding='utf-8'?>
<gpx version="1.1" creator="meshtastic-convert"
     xmlns="http://www.topografix.com/GPX/1/1">
  <trk>
    <name>Meshtastic Track</name>
    <trkseg>
      <trkpt lat="37.7749" lon="-122.4194">
        <time>2026-04-20T09:14:00Z</time>
        <ele>52</ele>
      </trkpt>
      ...
    </trkseg>
  </trk>
</gpx>
